# مسبحتي — Misbahati 📿

مسبحة إلكترونية بسيطة وأنيقة لعدّ التسبيح والأذكار، تعمل بالكامل دون اتصال بالإنترنت.

A simple, elegant digital prayer-beads (tasbih) counter that works fully offline.

## المزايا | Features

- ستة أذكار جاهزة بأهدافها: سبحان الله (33)، الحمد لله (33)، الله أكبر (34)، لا إله إلا الله (100)، أستغفر الله (100)، اللهم صلّ على محمد (100)
- اهتزاز عند إكمال كل جولة (على الأجهزة الداعمة)
- متابعة مجموع الجولات المكتملة ومجموع التسبيحات
- يعمل دون اتصال — بلا إعلانات، وبلا أي جمع أو تتبّع للبيانات
- خفيف جداً (~1.4MB)

## التقنية | Tech

Progressive Web App (HTML/CSS/JS) packaged for Android as a Trusted Web Activity (TWA) via Bubblewrap.
